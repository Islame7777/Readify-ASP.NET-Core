# 📚 Readify - ASP.NET Core Bookstore Management Platform

## Overview

Readify is a web-based bookstore management platform developed with ASP.NET Core MVC. The application allows users to browse books, manage shopping carts, place orders, and explore different literary categories. Administrators can manage books, genres, users, and customer orders through a dedicated administration panel.

## Features

### User Features
- Browse available books
- Search and filter books by category
- View book details
- Shopping cart management
- User account management
- Order placement and tracking

### Admin Features
- Book management (Create, Read, Update, Delete)
- Genre management
- User management
- Order management
- Statistics dashboard

## Installation

1. Clone the repository

```bash
git clone https://github.com/Islame7777/Readify-ASP.NET-Core.git
```

2. Configure the database connection string.

3. Run database migrations.

4. Start the application.

```bash
dotnet run
```

5. Open the application in your browser.
